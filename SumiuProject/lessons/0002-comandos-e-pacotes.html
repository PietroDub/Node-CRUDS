Comandos e pacotes

Antes de abrir o Sumiu, dá para nomear o comando e o pacote. A sequência inteira, da conexão até a tela, está no guia de montagem. Esta lição é só o começo: a pasta da API.

O que os três fizeram primeiro

Uma pasta, um package.json com "type": "module", e os pacotes que o index.js importa no topo. npm init -y cria o manifesto. Fonte: npm-init. O Vite fica para depois: ele gera o front, não a API.

mkdir api && cd api
npm init -y
npm install express mongoose dotenv cors cookie-parser
npm install -D nodemon

Cinco pacotes, cinco trabalhos

  • express escuta o HTTP. Hello world.
  • mongoose abre o Mongo. Conexão.
  • dotenv lê o .env. No Todo a primeira linha do index.js é import "dotenv/config".
  • cors deixa localhost:5173 chamar a API e mandar o cookie. cors.
  • cookie-parser preenche req.cookies, de onde o Sumiu tira o token.

argon2 e jsonwebtoken entram no login, não neste comando. A Bancada não os usa: a senha fica como veio. O modelo a repetir é o do Sumiu.

O Sumiu também lista um pacote chamado expres, sem o segundo s. Não instale esse. O servidor importa express.
