# A missão passou de três telas para a sequência inteira

O Pietro pediu um guia de estudo, imprimível, da criação da API até o front, cruzando Bancada, Sumiu e o Todo. Ele já escreveu os três, então o piso não é "o que é uma rota": é a ordem de montagem e o que cada pacote faz. A missão anterior (cadastro, login e lista do Sumiu) continua como caso, não como o destino. A próxima lição treina a ordem dos arquivos da API, não o JSX.
