Contrato da API

O que o servidor do Sumiu responde hoje. Fonte: API/index.js, API/routes/user.routes.js e API/routes/requisition.routes.js. Uma rota escrita noutro arquivo e não registrada com app.use não existe para o navegador. A sequência de montagem dos três projetos está no guia de montagem.

Montado

TelaChamadaCorpo
Cadastro POST /users name, email, password
Login POST /users/login email, password
Sair POST /users/logout nenhum; exige o cookie token

Base local: http://localhost:5000. O CORS aceita http://localhost:5173 com credenciais.

Requisições

index.js monta esse router em /requisitions.

ChamadaEfeito
POST /requisitionscria
GET /requisitionslista
GET /requisitions/:iduma requisição
PUT /requisitions/:idatualiza
DELETE /requisitions/:idapaga

Nenhuma dessas linhas passa pelo middleware do cookie. Logout e atualização de usuário passam.
