# Front do Sumiu — recursos

## Knowledge

- [Guia de rotas do Express](https://expressjs.com/en/guide/routing.html)
  Como `app.METHOD` e `app.use` registram o que o servidor responde. Use para: ler `API/index.js` e `API/routes` e saber qual chamada uma tela pode fazer.
- [Describing the UI (React)](https://react.dev/learn/describing-the-ui)
  Componentes, JSX e listas. Use para: desenhar cadastro, login e a lista sem inventar estrutura.
- [Your First Component (React)](https://react.dev/learn/your-first-component)
  Uma função que devolve JSX. Use para: a primeira tela, quando formos escrever o cadastro.
- [Guia do Vite](https://vite.dev/guide/)
  Projeto React com JSX, `npm run dev`, porta 5173. Use para: subir o front que já está em `FrontEnd/front`.
- [Using the Fetch API (MDN)](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch)
  `fetch`, método, corpo JSON e `credentials`. Use para: mandar o formulário e, no login, enviar o cookie.

## Wisdom (Communities)

- [Reactiflux](https://www.reactiflux.com/)
  Discord moderado, ligado à documentação do React. Use para: travar num formulário ou numa lista e ouvir alguém de fora deste chat.
- [r/reactjs](https://www.reddit.com/r/reactjs/)
  Discussão de código React com moderação. Use para: mostrar um componente curto e pedir leitura.
